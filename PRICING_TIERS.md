# Pricing Tiers: Free vs Premium

## Two-Tier System

### 🆓 FREE TIER
**Cost to you: ~$0.00 - $0.50 per user/month**

**Features:**
- ✅ 10 prompt enhancements per week
- ✅ 5 "Ask" questions per day
- ✅ Basic style templates (default, concise, detailed)
- ✅ View last 20 history items
- ✅ "Improve" button in AI chats
- ✅ Keyboard shortcuts
- ✅ Community support

**Your API Costs:**
- Average prompt: ~130 tokens input, ~260 tokens output
- 10 enhancements/week × 4.3 weeks = 43 enhancements/month
- Cost per enhancement: ~$0.00012 (130 × $0.10/1M + 260 × $0.40/1M)
- **Monthly cost per free user: ~$0.005** (0.5 cents)
- With 5 questions/day: +$0.018 = **~$0.02/month per free user**

**Realistic estimate with overhead: $0.00 - $0.10/month per free user**
- Most users stay within free tier limits
- Some heavy users might cost more
- Average: **~$0.02/month per free user**

---

### ⭐ PREMIUM TIER
**Price: $19.99/month per user**
**Cost to you: ~$0.50 - $2.00 per user/month**

**Features:**
- ✅ **Unlimited** prompt enhancements
- ✅ **Unlimited** "Ask" questions
- ✅ All style templates (including advanced)
- ✅ Unlimited history (50+ items)
- ✅ Export history (CSV/JSON)
- ✅ Priority API access
- ✅ Priority support
- ✅ Custom style creation (unlimited)

**Your API Costs:**
- Heavy user: ~100 enhancements/month
- Average: ~50 enhancements/month
- Light user: ~20 enhancements/month
- Cost per enhancement: ~$0.00012
- **Monthly cost per premium user: $0.006 - $0.012** (0.6 - 1.2 cents per enhancement)
- Average premium user: **~$0.60/month** in API costs

**Realistic estimate: $0.50 - $2.00/month per premium user**
- Most premium users: ~50 enhancements/month = **~$0.60/month**
- Heavy users: ~200 enhancements/month = **~$2.40/month**
- Average: **~$1.00/month per premium user**

## 💡 Cost Optimization Tips

1. **Use Gemini Free Tier**: First 1,500 requests/day are free!
   - If you stay under 1,500 requests/day total, API costs = $0.00
   - Only pay for requests beyond free tier

2. **Implement Caching**: 
   - Cache similar prompts
   - Reduce duplicate API calls
   - Save ~20-30% on costs

3. **Rate Limiting**:
   - Prevent abuse
   - Limit free tier strictly
   - Monitor usage patterns

4. **Batch Processing** (if applicable):
   - Batch API: $0.05 input / $0.20 output per 1M tokens
   - 50% cheaper than regular API!
