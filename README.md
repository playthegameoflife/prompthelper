# Prompt Helper Gemini

Intelligent prompt refinement for AI chats. Enhance Text, Code, Image, and Video prompts with one click—directly in your favorite AI chat interfaces.

## Features

- 🚀 **One-Click Enhancement**: Fast, efficient AI refinement in any supported chat
- 🎯 **Multiple Enhancement Modes**: Text, Code, Image, and Video prompt optimization
- ⚡ **Fast & Efficient**: Optimized for speed and low cost
- 📝 **Enhancement History**: View and reuse your recently enhanced prompts
- ⌨️ **Keyboard Shortcuts**: Quick access with `Ctrl+Shift+E` (or `Cmd+Shift+E` on Mac)
- 🎨 **Beautiful UI**: Modern, clean interface inspired by Apple's design language
- 🔒 **Privacy First**: API key stored locally, never shared
- 💰 **Free Tier Available**: Generous free usage limits from Google

## Supported Platforms

- ChatGPT (chat.openai.com)
- Google Gemini (gemini.google.com)
- Anthropic Claude (claude.ai)
- Grok (x.com)
- Perplexity (perplexity.ai)

## Installation

### From Chrome Web Store

1. Visit the [Chrome Web Store](https://chrome.google.com/webstore) (link to be added)
2. Click "Add to Chrome"
3. Follow the setup instructions below

### Manual Installation (Development)

1. Clone or download this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the extension directory

## Setup

### 1. Get Your Gemini API Key

- Visit [Google AI Studio](https://aistudio.google.com/api-keys) to get your free Gemini API key
- Free tier includes generous usage limits
- No credit card required for free tier

### 2. Configure the Extension

1. Click the Prompt Helper Gemini icon in your browser toolbar
2. Navigate to the "Setup" tab
3. Enter your Gemini API key
4. Click "Save & Activate"

### 3. Start Enhancing

- **In Chat Interfaces**: Look for the ✨ button next to the send button
- **From Popup**: Enter your prompt in the Enhance tab and click "Enhance Prompt"
- **Keyboard Shortcut**: Press `Ctrl+Shift+E` (or `Cmd+Shift+E` on Mac) to enhance the current prompt
- **Context Menu**: Right-click selected text and choose "Architect: Enhance"

## Enhancement Modes

- **Text**: Optimized for general text generation and conversation
- **Code**: Specialized for code generation requests
- **Image**: Enhanced prompts for image generation (DALL-E, Midjourney, etc.)
- **Video**: Detailed prompts for video generation (Runway, Pika, Luma, etc.)

## How It Works

1. **Smart Detection**: The extension automatically detects the best enhancement mode based on your prompt content
2. **Enhancement**: Your prompt is sent to your chosen AI provider with specialized instructions
3. **Application**: The enhanced prompt is automatically inserted into the input field
4. **History**: All enhancements are saved locally for easy reuse

## Privacy & Security

- ✅ All API keys are stored locally in your browser
- ✅ No data is sent to third-party servers (except your chosen AI provider)
- ✅ No tracking or analytics
- ✅ Open source code for transparency

## Troubleshooting

### The ✨ button doesn't appear

- Make sure you're on a supported platform (ChatGPT, Gemini, Claude, etc.)
- Refresh the page
- Check that the extension is enabled in `chrome://extensions/`

### API errors

- **Invalid API Key**: Verify your API key in the Setup tab
- **Quota Exceeded**: Check your API usage limits
- **Timeout**: The request took too long. Try again or check your internet connection

### Enhancement not working

- Ensure your API key is correctly configured
- Check that you have sufficient API credits/quota
- Try refreshing the page
