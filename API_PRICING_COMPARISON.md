# API Pricing Comparison - Cheapest Models for Prompt Enhancement
*Updated: January 2025*

## 🏆 Winner: Google Gemini (FREE Tier Available!)

### Google Gemini - Best Value

**Free Tier:**
- ✅ **Free input and output tokens** up to usage limits
- ✅ **500 requests per day** (RPD) for grounding features
- ✅ **1,500 requests per day** (RPD) in paid tier before extra charges
- ✅ **$0.00** - Completely free for standard API calls!

**Paid Tier (if you exceed free limits):**
- **Gemini 2.5 Flash-Lite**: 
  - Input: **$0.10** per 1M tokens (text/image/video)
  - Output: **$0.40** per 1M tokens (including thinking)
  - Batch API: $0.05 input / $0.20 output per 1M tokens
- **Gemini 1.5 Flash**: 
  - Input: $0.075 per 1M tokens (up to 128K), $0.15 (over 128K)
  - Output: $0.30 per 1M tokens (up to 128K), $0.60 (over 128K)
- **Gemini 2.5 Flash**: 
  - Input: $0.30 per 1M tokens
  - Output: $2.50 per 1M tokens

**Best Model for Cost:** `gemini-2.5-flash-lite` (free tier) or `gemini-1.5-flash-002`

## ⚠️ Important Notes

1. **Free Tier Limits:**
   - Gemini: 1,500 requests/day (very generous!)
   - Most others: No free tier or very limited

2. **Token Counting:**
   - Prices are per million tokens
   - 1 token ≈ 0.75 words (English)
   - Your prompts are typically 50-200 tokens

3. **Rate Limits:**
   - Free tiers have rate limits
   - Paid tiers have higher limits
   - Check each provider's documentation

4. **Quality vs Cost:**
   - Cheaper models may have lower quality
   - Test different models for your use case
   - Prompt enhancement doesn't need GPT-4 level quality
